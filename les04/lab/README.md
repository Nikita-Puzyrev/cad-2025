# Отчет о лабораторной работе

## Цель работы
Необходимо перейти на новое, более простое конфигурирование приложения с помощью аннотаций, добавить функционал по представлению таблиц в виде HTML и измерить скорость выполнения нашего кода с помощью инструментов АОП. 

## Выполнение работы
Работа выполнена в полном объеме: осуществлен переход на аннотационный способ конфигурирования приложения, внедрен функционал рендеринга таблиц в HTML-формате, а также с помощью инструментов АОП реализован замер времени выполнения программного кода.

## Выводы
В ходе работы были изучены и внедрены аннотационный подход к конфигурации приложения и механизм представления таблиц в виде HTML. Кроме того, применение инструментов АОП позволило успешно решить задачу по измерению скорости выполнения кода.
