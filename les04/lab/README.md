# Отчет о лаботаротоной работе

## Цель работы
Необходимо перейти на новое, более простое конфигурирование приложения с помощью аннотаций, добавить функционал по представлению таблиц в виде HTML и измерить скорость выполнения нашего кода c помощью инструментов АОП. 
## Выполнение работы
В ходе выполнения лабораторной работы были последовательно реализованы следующие этапы:
1. **Рефакторинг конфигурации:** осуществлен переход на более простой и современный подход к конфигурированию приложения с использованием аннотаций.
2. **Визуализация данных:** добавлен функционал для преобразования и представления табличных данных в формате HTML.
3. **Профилирование производительности:** с использованием инструментов аспектно-ориентированного программирования (АОП) настроено измерение времени выполнения программного кода.
## Выводы
В результате выполнения лабораторной работы были успешно освоены и применены на практике следующие концепции:
* Выполнен переход на аннотационное конфигурирование приложения, что упростило поддержку проекта.
* Реализован модуль генерации HTML-представления таблиц.
* Настроены аспекты (АОП) для замера скорости выполнения участков кода, что позволяет эффективно проводить анализ производительности.
