# Лабораторная работа №2. Spring MVC

Цель работы — сделать веб-интерфейс списка задач. Контроллер передаёт задачи в шаблон Thymeleaf. Хранилище в памяти выдаёт каждой задаче свой идентификатор.

Из каталога `sem2` запустите `./gradlew :lab2:bootRun` на Java 17 и откройте `http://localhost:8080/`.

1. Создайте задачу с названием и описанием.
2. Отметьте её выполненной, затем верните в работу.
3. Найдите задачу по части названия или описания. Поиск без учёта регистра — вариант 5 дополнительного задания.
4. Удалите задачу.
