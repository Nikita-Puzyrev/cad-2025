## Цель работы

Разработать веб-приложение «Список задач» с использованием Spring MVC и шаблонизатора Thymeleaf.

## Ход работы

В соответствии с методическими указаниями созданы классы `Task`, репозиторий, сервис и контроллер `TaskController`. Отображение списка задач реализовано на странице `index.html` с применением Thymeleaf.

Из дополнительных заданий реализованы категории задач (Учёба / Личные дела / Работа) и подтверждение действия перед удалением. Оформление страницы изменено минимально: заданы отступы для удобства работы с интерфейсом.

После запуска приложение доступно по адресу http://localhost:8080/. Через веб-интерфейс выполняются добавление задачи, отметка о выполнении и удаление.

## Запуск

```
cd sem2/lab2
mvn spring-boot:run
```

## Вывод

Реализовано веб-приложение для ведения списка задач с серверным формированием HTML-страниц. Контроллер возвращает имя шаблона Thymeleaf. Получены навыки работы со Spring MVC.
