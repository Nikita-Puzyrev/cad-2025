# Отчет по лабораторной работе №2

Тема: создание проекта Spring MVC.

## Цель

Создать список задач с веб-интерфейсом.

## Выполнение

Класс Task хранит название, описание и статус задачи. TaskController принимает запросы, TaskService выполняет операции, TaskRepository хранит задачи в памяти. Для отображения страницы используется Thymeleaf.

Можно добавлять и удалять задачи, отмечать их выполненными и возвращать в работу. Дополнительное задание: поиск по названию и описанию без учета регистра.

## Вывод

Создано приложение Spring MVC для управления задачами. Данные передаются из контроллера в шаблон Thymeleaf и хранятся до остановки приложения.
