## Цель работы

Разработать мобильный клиент для REST API лабораторной работы №5 на платформе Android.

## Ход работы

Исходный код приложения размещён в каталоге `TodoAndroid`. После прохождения экрана входа выполняется загрузка списка задач с использованием библиотеки Retrofit. Для обращения к серверу с эмулятора Android используется адрес `10.0.2.2:8080`, соответствующий localhost на компьютере разработчика.

Перед запуском мобильного приложения необходимо запустить сервер из лабораторной работы №5. Далее в Android Studio открывается проект `sem2/lab6/TodoAndroid`, выбирается эмулятор и выполняется сборка и запуск. Учётные данные совпадают с серверными: `user` / `password`.

При недоступности сервера пользователю отображается сообщение об отсутствии связи.

## Запуск

Сервер:

```
cd sem2/lab5/server
mvn spring-boot:run
```

Клиент: Android Studio → Open `sem2/lab6/TodoAndroid` → Run.

## Вывод

Мобильное приложение успешно взаимодействует с REST API сервера. Авторизация и получение списка задач на эмуляторе выполняются корректно. Получены навыки разработки Android-клиента к существующему серверному API.
