# Лабораторная работа №6. Android-клиент

Цель работы — загрузить список задач с сервера лабораторной №5. Приложение отправляет учётные данные через HTTP Basic с Retrofit, проверяет результат входа и отображает список через RecyclerView.

Минимальная версия Android — 7.0 (API 24).

1. Запустите сервер [лабораторной №5](../lab5/README.md) на порту 8080 и добавьте задачу.
2. Запустите эмулятор Android с API 35. Нужны JDK 17 и SDK Platform 35.
3. Из каталога `sem2/lab6` выполните `./gradlew installDebug` с настроенным `ANDROID_HOME` или откройте этот каталог в Android Studio и запустите приложение.
4. Откройте «Список задач» и войдите как `user` с паролем, заданным на сервере.

Адрес `10.0.2.2:8080` внутри эмулятора ведёт на сервер хоста. Разрешение на HTTP в приложении задано для этого адреса. При неверном пароле экран входа показывает ошибку, при успешном входе видны названия, описания и статусы задач.

На эмуляторе API 35 проверены отказ при неверном пароле и загрузка задачи из PostgreSQL через сервер.
