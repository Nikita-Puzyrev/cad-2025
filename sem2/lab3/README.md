# Лабораторная работа №3. Spring Security

Цель работы — добавить вход и права доступа к списку задач из второй лабораторной. Для дополнительного задания добавлена роль `SEARCHER`, которой доступен поиск.

Из каталога `sem2` запустите `./gradlew :lab3:bootRun` на Java 17 и откройте `http://localhost:8080/`. Пароль учебных пользователей — `password`. Для другого пароля задайте переменную `TASKS_PASSWORD`.

| Вход | Роль | Возможности |
| --- | --- | --- |
| `user` | `USER` | Просмотр и добавление |
| `moderator` | `MODERATOR` | Просмотр, поиск, добавление, смена статуса и удаление |
| `searcher` | `SEARCHER` | Просмотр и поиск |

Гость переходит на форму входа. Для недоступной операции сервер возвращает HTTP 403. Формы изменения задач отправляют POST с CSRF-токеном.
