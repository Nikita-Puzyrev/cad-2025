# Отчет по лабораторной работе №3

Тема: создание проекта Spring Security.

## Цель

Добавить вход в приложение и разграничить права пользователей.

## Выполнение

В приложение из работы №2 добавлен Spring Security. Пользователи заданы в SecurityConfig. Изменять статус и удалять задачи может только модератор.

Дополнительное задание: роль SEARCHER для поиска задач.

| Логин | Пароль | Возможности |
| --- | --- | --- |
| user | password | Просмотр и добавление |
| moderator | password | Просмотр, добавление, изменение статуса и удаление |
| searcher | password | Просмотр, добавление и поиск |

## Вывод

Добавлена авторизация и проверка прав. Доступные действия зависят от роли пользователя.
