## Цель работы

Добавить в приложение ToDo механизмы аутентификации и авторизации на основе Spring Security.

## Ход работы

На основе лабораторной работы №2 настроена форма входа. В классе `SecurityConfig` созданы три учётные записи с паролем `password`:
- user;
- moderator;
- admin.

Операции удаления задачи и отметки о выполнении защищены аннотацией `@PreAuthorize` и доступны пользователям с ролью MODERATOR. Для роли ADMIN в рамках дополнительного задания реализована очистка всего списка задач.

При обращении к защищённым ресурсам выполняется перенаправление на страницу `/login`. Проверка показала: под учётной записью user удаление недоступно; под учётной записью moderator операция выполняется успешно.
