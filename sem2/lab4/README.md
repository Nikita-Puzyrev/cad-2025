# Лабораторная работа №4. Хранение задач в базе данных (JPA)

**Студентка:** Севрюкова Валерия Сергеевна  
**Группа:** 12002453  

## Цель работы

Организовать постоянное хранение задач в базе данных с применением Spring Data JPA.

## Ход работы

Класс `Task` преобразован в сущность JPA (`@Entity`). Вместо хранения в оперативной памяти используется интерфейс `JpaRepository`. В модель данных добавлены категория, приоритет, дата создания и сущность подзадач `SubTask`.

Согласно методическим указаниям предусмотрено использование PostgreSQL. По умолчанию подключена встраиваемая СУБД H2 с файловым хранилищем в каталоге `./data`. Параметры подключения к PostgreSQL вынесены в файл `application-postgres.properties`.

Учётные записи пользователей соответствуют лабораторной работе №3: user, moderator, admin; пароль — `password`.

После перезапуска приложения сохранённые задачи остаются доступными, что подтверждает корректность записи в базу данных.

## Запуск

```
cd sem2/lab4
mvn spring-boot:run
```

Запуск с профилем PostgreSQL (при наличии настроенной СУБД):

```
mvn spring-boot:run -Dspring-boot.run.profiles=postgres
```

## Вывод

Задачи сохраняются в базе данных и доступны после перезапуска приложения. Обеспечена работа с H2 и возможность перехода на PostgreSQL. Получены навыки использования Spring Data JPA.
