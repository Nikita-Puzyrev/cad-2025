# Отчет по лабораторной работе №4

Тема: Spring и PostgreSQL.

## Цель

Перенести хранение задач из памяти в базу данных.

## Выполнение

Создана сущность Task и репозиторий Spring Data JPA. Задачи хранятся в таблице tasks PostgreSQL. Сохраняются описание, статус, приоритет и время создания.

Пользователь user просматривает и добавляет задачи. Пользователь moderator также меняет статус и удаляет задачи. Пароль обоих пользователей: password.

Из дополнительного задания выполнен первый пункт: добавлены приоритет и время создания. Приоритет задается числом от 1 до 3, где 1 — высокий.

## Вывод

Задачи сохраняются в PostgreSQL через JPA. После перезапуска приложения записи остаются в базе.
