# Лабораторная работа №4. Spring Data JPA и PostgreSQL

Цель работы — сохранять задачи и связанные данные в PostgreSQL. Список, поиск и права доступа работают по правилам предыдущих лабораторных.

Создайте базу `todo_db` и укажите параметры подключения к PostgreSQL.

| Переменная | Значение по умолчанию |
| --- | --- |
| `TASKS_DB_URL` | `jdbc:postgresql://localhost:5432/todo_db` |
| `TASKS_DB_USER` | `postgres` |
| `TASKS_DB_PASSWORD` | Пустой пароль |
| `TASKS_PASSWORD` | `password` для первоначального создания учебных пользователей |

Из каталога `sem2` запустите `./gradlew :lab4:bootRun` на Java 17 и откройте `http://localhost:8080/`. При первом запуске Hibernate создаёт таблицы. Учётные записи `user`, `moderator` и `searcher` получают пароли в виде хешей BCrypt. При повторном запуске их пароли берутся из базы.

| Таблица | Содержимое |
| --- | --- |
| `tasks` | Задача, дата создания, приоритет, категория и ссылка на автора |
| `sub_tasks` | Описание, статус и ссылка на родительскую задачу |
| `users` | Имя, email, хеш пароля и роль |
| `login_history` | Пользователь, время успешного входа и IP-адрес |
| `task_history` | Идентификатор задачи, время изменения и снимки состояния до и после |

Войдите как `user`, добавьте задачу и откройте «Подробнее». Войдите как `moderator`, измените приоритет и категорию, добавьте подзадачу и отметьте её выполненной. Смена статуса и параметров задачи сохраняется в истории. Записи истории доступны в базе после удаления задачи.

Проверены сохранение полей и связей в PostgreSQL, фиксация IP и состояние задачи до и после изменения.
