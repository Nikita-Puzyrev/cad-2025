## Цель работы

Разработать REST API для управления списком сообщений с использованием фреймворка Spring Boot.

## Ход работы

Создан Maven-проект на базе Spring Boot (Java 17, зависимость `spring-boot-starter-web`). Обработка HTTP-запросов реализована в классе `MessageController`.

Реализованы следующие операции:
- `GET /` — возврат строки Hello, World!;
- `GET /messages` — получение списка сообщений;
- `POST /messages` — добавление сообщения;
- `GET /messages/{index}` — получение сообщения по индексу;
- `PUT /messages/{index}` — изменение сообщения;
- `DELETE /messages/{index}` — удаление сообщения.

Дополнительно реализованы подсчёт количества сообщений и очистка списка. При добавлении выполняется проверка: сообщение не должно быть пустым, не должно дублировать существующие записи и не должно превышать 200 символов.

Проверка работоспособности выполнена средствами браузера и Postman по адресу `http://localhost:8080/messages`. Для метода POST передавалось тело в формате JSON, например `"Привет"`.

## Запуск

```
cd sem2/lab1
mvn spring-boot:run
```
