# Отчет по лабораторной работе №1

Тема: создание проекта Spring Boot.

## Цель

Создать приложение для хранения сообщений и обработки HTTP-запросов.

## Выполнение

Сообщения хранятся в списке в памяти. Контроллер позволяет получить список, добавить, изменить и удалить сообщение. Индексы начинаются с нуля.

Дополнительное задание: очистка списка и подсчет сообщений.

| Запрос | Действие |
| --- | --- |
| GET /messages | Получить список |
| POST /messages | Добавить сообщение из тела запроса |
| PUT /messages/{index} | Изменить сообщение |
| DELETE /messages/{index} | Удалить сообщение |
| DELETE /messages | Очистить список |
| GET /messages/count | Получить количество сообщений |

## Вывод

Создано приложение Spring Boot с обработкой GET, POST, PUT и DELETE. После остановки приложения список сообщений очищается.
