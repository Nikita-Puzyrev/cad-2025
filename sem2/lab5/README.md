# Лабораторная работа №5. Сервер и клиент Swing

Цель работы — управлять задачами из настольного приложения. Сервер использует базу и учётные записи лабораторной №4. Подготовьте PostgreSQL по [инструкции](../lab4/README.md).

Из каталога `sem2` запустите сервер командой `./gradlew :lab5:server:bootRun`, а в другом терминале запустите клиент командой `./gradlew :lab5:client:run`. Требуется Java 17. Сервер принимает локальные подключения на `127.0.0.1:8080`.

| REST-запрос | Доступ и результат |
| --- | --- |
| `GET /api` | Список задач для всех учебных ролей |
| `GET /api/{id}` | Данные задачи, подзадачи и история изменений |
| `GET /api/login-history` | Последние входы текущего пользователя |
| `POST /api` | Создание задачи для `USER` и `MODERATOR` |
| `DELETE /api/{id}` | Удаление задачи для `MODERATOR` |

```sh
curl -u user:password http://127.0.0.1:8080/api
curl -u user:password -H 'Content-Type: application/json' \
    --data '{"title":"Отчёт","description":"Проверить данные","priority":"HIGH","category":"Учёба"}' \
    http://127.0.0.1:8080/api
```

После входа клиент показывает таблицу со статусом, приоритетом, категорией, автором и датой создания. Нажмите заголовок столбца для сортировки. Кнопка «Подробнее» открывает описание, подзадачи и историю изменений. Кнопка «Мои входы» показывает время и IP. Добавление передаёт данные в PostgreSQL через сервер, а на удаление сервер возвращает HTTP 403 пользователю без прав модератора.

API проверяет учётные данные через Basic при каждом запросе и записывает успешные аутентификации в «Мои входы».

Проверены ответы API с Basic-аутентификацией, создание и удаление в PostgreSQL и возврат дополнительных сведений. Клиент собран в запускаемый дистрибутив.
