# Отчет по лабораторной работе №5

Тема: создание клиента.

## Цель

Создать настольный клиент для работы с сервером Spring.

## Выполнение

В папке server находится сервер с PostgreSQL и REST API. В папке client находится приложение Java Swing. Для входа используется Basic Auth.

Клиент отображает таблицу с описанием, статусом, приоритетом и временем создания задач. Можно добавить задачу, обновить список и удалить выбранную запись. Сортировка выполняется нажатием на заголовок столбца.

Удалять задачи может только moderator. Пользователь user может получать список и добавлять задачи. Пароль обоих пользователей: password.

| Запрос | Назначение |
| --- | --- |
| GET /api | Получить список задач |
| POST /api | Добавить задачу |
| DELETE /api/{id} | Удалить задачу |

## Вывод

Клиент получает и изменяет задачи через HTTP-запросы. Сервер работает с базой данных и проверяет права пользователя.
