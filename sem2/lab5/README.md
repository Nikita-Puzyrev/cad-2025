## Цель работы

Разделить приложение на серверную часть с REST API и десктопный клиент на платформе Swing.

## Ход работы

Проект состоит из двух модулей:
- `server` — серверное приложение ToDo с хранением данных в базе и REST API по пути `/api`;
- `client` — клиентское приложение на Swing (`LoginForm`, `TaskManagerForm`).

Клиент выполняет аутентификацию по протоколу Basic Auth, загружает список задач, добавляет и удаляет записи. Реализована сортировка. В списке отображаются категория и приоритет задачи.

Порядок проверки: сначала запускается сервер, затем клиент. Вход выполняется под учётной записью `user` / `password`. Для удаления требуется роль moderator; при её отсутствии сервер возвращает отказ в выполнении операции.

## Запуск

Сервер:

```
cd sem2/lab5/server
mvn spring-boot:run
```

Клиент:

```
cd sem2/lab5/client
mvn -q compile exec:java
```

## Вывод

Клиентское приложение взаимодействует с сервером по REST API. Ограничения доступа по ролям на стороне сервера сохраняются и корректно обрабатываются клиентом. Получены навыки разработки клиент-серверного приложения.
