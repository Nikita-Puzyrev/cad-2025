# Отчет о лаботаротоной работе

## Цель работы
Добавление ролевого доступа.
## Выполнение работы
В ходе выполнения лабораторной работы были последовательно реализованы следующие этапы:
1. **Настройка безопасности:** интегрированы компоненты для управления аутентификацией и авторизацией пользователей.
2. **Определение ролевой модели:** созданы сущности или роли пользователей, определяющие уровень их доступа к системе.
3. **Разграничение прав:** настроены правила доступа к различным эндпоинтам и ресурсам приложения в зависимости от назначенной пользователю роли.

## Выводы
В результате выполнения лабораторной работы были успешно решены поставленные задачи:
* Внедрен механизм ролевого доступа (RBAC).
* Настроено корректное разделение прав пользователей, что повысило уровень защищенности и безопасности разработанного приложения.
