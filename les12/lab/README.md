# Отчет о лабораторной работе

## Цель работы
Разработка Web-приложений с использованием технологии Spring MVC.

## Выполнение работы
Работа выполнена в полном объеме: произведена настройка окружения Spring MVC, разработаны контроллеры для обработки клиентских запросов, а также созданы необходимые представления для вывода информации.

## Выводы
В ходе работы были изучены возможности фреймворка Spring MVC, в результате чего было успешно разработано и сконфигурировано полноценное веб-приложение, реализующее паттерн Model-View-Controller.
