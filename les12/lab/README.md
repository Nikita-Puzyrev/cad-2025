# Отчет о лаботаротоной работе

## Цель работы
Разработка Web-приложений с использованием технологии Spring MVC.
## Выполнение работы
В ходе выполнения лабораторной работы были последовательно реализованы следующие этапы:
1. **Настройка конфигурации MVC:** подключены и настроены компоненты инфраструктуры Spring MVC (DispatcherServlet, маппинг запросов и резолверы представлений).
2. **Реализация контроллеров:** разработаны управляющие классы (контроллеры) для обработки входящих HTTP-запросов, взаимодействия с бизнес-логикой и передачи данных в модель.
3. **Создание представлений:** настроен пользовательский интерфейс для отображения обработанных данных клиенту.

## Выводы
В результате выполнения лабораторной работы были успешно освоены принципы проектирования веб-приложений с использованием паттерна MVC на базе Spring:
* Настроена конфигурация Spring MVC.
* Разработаны контроллеры и представления, обеспечивающие полноценный цикл обработки клиентских запросов и формирования ответов.
