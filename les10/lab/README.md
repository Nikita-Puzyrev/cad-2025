# Отчет о лабораторной работе

## Цель работы
Реализация веб-интерфейса и интеграция возможностей веб-приложения в существующую архитектуру проекта.

## Выполнение работы
Работа выполнена в полном объеме: настроено веб-окружение приложения, разработаны контроллеры для обработки HTTP-запросов и ответов, а также внедрена поддержка работы в качестве веб-приложения.

## Выводы
В ходе работы проект был успешно дополнен веб-слоем, благодаря чему приложение научилось обрабатывать веб-запросы и функционировать в качестве полноценной веб-системы.
