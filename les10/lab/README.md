# Отчет о лаботаротоной работе

## Цель работы
Добавление Web-приложений нашему приложению
## Выполнение работы
В ходе выполнения лабораторной работы были последовательно реализованы следующие этапы:
1. **Настройка веб-окружения:** добавлены необходимые зависимости и конфигурации для запуска приложения в качестве веб-сервера.
2. **Разработка контроллеров:** созданы контроллеры для обработки входящих HTTP-запросов и формирования ответов клиенту.
3. **Интеграция:** новые веб-компоненты успешно встроены в общую структуру слоистой архитектуры приложения.

## Выводы
В результате выполнения лабораторной работы были успешно решены поставленные задачи:
* Проект расширен до полноценного веб-приложения.
* Настроена обработка HTTP-запросов, что позволяет взаимодействовать с системой через веб-интерфейс.
