# Отчет о лаботаротоной работе

## Цель работы
Переход с использования Spring JDBC на использование ORM Hibernate и Spring Data. Также расширение нашего приложения новыми сущностями и приведение структуры приложения в соответствие со "слоистой архитектурой".
## Выполнение работы
В ходе выполнения лабораторной работы были последовательно реализованы следующие этапы:
1. **Миграция слоя данных:** осуществлен полный перевод приложения с Spring JDBC на ORM Hibernate и Spring Data для более эффективного управления сущностями и базами данных.
2. **Расширение доменной модели:** добавлены новые сущности, расширяющие функциональные возможности приложения.
3. **Рефакторинг архитектуры:** структура проекта была переработана и приведена в строгие соответствия принципам слоистой архитектуры (Layered Architecture).

## Выводы
В результате выполнения лабораторной работы были успешно решены поставленные задачи:
* Осуществлен переход на Hibernate и Spring Data, что упростило взаимодействие с персистентными данными.
* Добавлены новые сущности для расширения предметной области приложения.
* Структура приложения приведена в соответствие со слоистой архитектурой, что повысило модульность, читаемость и поддерживаемость кода.
