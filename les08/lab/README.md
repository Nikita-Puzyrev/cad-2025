# Отчет о лабораторной работе

## Цель работы
Переход с использования Spring JDBC на использование ORM Hibernate и Spring Data. Также расширение нашего приложения новыми сущностями и приведение структуры приложения в соответствие со "слоистой архитектурой".

## Выполнение работы
Работа выполнена в полном объеме: произведен переход с Spring JDBC на Hibernate и Spring Data, модель данных расширена новыми сущностями, а структура приложения приведена в соответствие со слоистой архитектурой.

## Выводы
В ходе работы был успешно выполнен переход на ORM Hibernate и Spring Data, дополнена структура данных новыми сущностями, а также перестроена архитектура приложения в соответствии со слоистым шаблоном проектирования, что улучшило организацию кода.
