#

# 

# \## Используемые технологии

# \- Java 17

# \- Gradle 8.12

# \- Kotlin DSL

# \- Spring Context 6.2.2

# \- JUnit Jupiter

# 

# \## Описание приложения

# 

# В ходе лабораторной работы разработано консольное приложение \*\*product-table\*\*, предназначенное для чтения информации о товарах магазина из CSV-файла и отображения данных в виде таблицы.

# 

# Приложение использует Spring Framework для создания объектов и управления зависимостями между компонентами.

# 

# \## Структура приложения

# 

# Реализованы следующие классы и интерфейсы:

# 

# 1\. \*\*Product\*\* — класс, описывающий сущность «Товар».

# 2\. \*\*Reader\*\* — интерфейс для чтения данных.

# 3\. \*\*ResourceFileReader\*\* — чтение CSV-файла из ресурсов приложения.

# 4\. \*\*Parser\*\* — интерфейс преобразования данных.

# 5\. \*\*CSVParser\*\* — преобразование строк CSV в объекты Product.

# 6\. \*\*ProductProvider\*\* — интерфейс получения списка товаров.

# 7\. \*\*ConcreteProductProvider\*\* — получение списка товаров с использованием Reader и Parser.

# 8\. \*\*Renderer\*\* — интерфейс отображения информации.

# 9\. \*\*ConsoleTableRenderer\*\* — вывод списка товаров в консоль в виде таблицы.

# 10\. \*\*AppConfig\*\* — Java-конфигурация Spring.

# 11\. \*\*App\*\* — главный класс приложения.

# 

# \## Принцип работы

# 

# 1\. Spring создаёт необходимые компоненты с помощью аннотаций `@Configuration` и `@Bean`.

# 2\. ResourceFileReader считывает данные из файла `product.csv`.

# 3\. CSVParser преобразует строки файла в объекты Product.

# 4\. ConcreteProductProvider формирует список товаров.

# 5\. ConsoleTableRenderer отображает товары в консоли в табличном виде.

# 

# Файл `product.csv` находится по пути:

# 

# `app/src/main/resources/product.csv`

#

# 

# Для запуска приложения:

#
