# Отчет о лаботаротоной работе

## Цель работы
Необходимо создать каркас приложения и разобраться с конфигурированием Spring приложений на основе Java-классов. Также нужно написать загрузчик CSV файлов и парсер данных. 
## Выполнение работы
В ходе выполнения лабораторной работы были последовательно реализованы следующие этапы:
1. **Проектирование архитектуры:** создан базовый каркас приложения с корректной структурой проекта.
2. **Конфигурация:** настроено конфигурирование Spring-приложения с использованием подходов на основе Java-классов (`@Configuration`).
3. **Обработка данных:** разработаны компоненты для загрузки CSV-файлов из внешних источников и их последующего парсинга в структуры данных приложения.## Выводы сделаны
В результате выполнения лабораторной работы были освоены базовые принципы работы со Spring и структура современного Java-приложения. 
Успешно решены поставленные задачи:
* Спроектирован и развернут каркас приложения.
* Настроена конфигурация на основе Java-классов.
* Реализованы надежные механизмы загрузки и синтаксического анализа CSV-данных.
